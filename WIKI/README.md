# NOFX 个人版 Wiki（接力与归档）

本目录用于沉淀“稳定知识”（Why/What/How），让新的 AI 或协作者在不通读全仓库的情况下，快速对齐本项目的个人化改造目标、架构与规则。

## 你应该先读什么（建议顺序）

1) `WIKI/AI-HANDOFF.md`：最短路径理解“我们改了什么、为什么改、下一步怎么做”  
2) `WIKI/ARCHITECTURE.md`：端到端链路（策略→数据→AI→执行→落库→UI）与关键语义  
3) `WIKI/OPERATIONS.md`：本地长期跑、备份/恢复、观测、故障处理  
4) `WIKI/DEV-RULES.md`：迭代规则（如何改、改哪里、怎么保持可 `git pull`）  
5) `WIKI/TODO-RULES.md`：`todo/` 的存放规则与维护方式（计划/里程碑/验收）

## WIKI 与 todo 的分工

- `WIKI/`：长期有效的知识与规则（稳定、不频繁变动）。  
- `todo/`：阶段计划、任务清单、进度打勾、验收步骤（执行用、会频繁更新）。  

## 约束与目标

- 不改语言栈：保持 Go/React，便于跟进上游开源仓库更新。  
- 先模拟盘（paper）再考虑实盘：paper 不能触发真实交易所下单。  
- 追求：回测/模拟严谨、风控强、可解释、可观测、单人本地长期运行。
